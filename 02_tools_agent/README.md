# 2단계 · 도구(Tool)와 에이전트

## 목표

- LLM이 직접 함수를 실행하는 게 아니라 **"이 함수를 이 값으로 불러 줘"라고 요청만** 한다는 걸 이해한다.
- 그 요청 → 실행 → 결과 전달 과정을 **손으로 한 번** 해 보고,
- 같은 일을 `create_agent`가 **자동으로 반복**해 준다는 걸 확인한다.

## 실행 순서

```bash
python 02_tools_agent/step1_tool_call_by_hand.py
python 02_tools_agent/step2_agent.py
```

## 핵심 개념

### 도구 = 설명이 붙은 파이썬 함수

```python
@tool
def get_service_owner(service_name: str) -> dict:
    """서비스 이름으로 담당 팀과 온콜 담당자를 찾는다."""   # ← LLM이 읽는 설명서
    ...
```

LLM은 함수 코드를 보지 않습니다. **함수 이름, 설명(docstring), 인자 이름·타입**만 보고
"언제 이 도구를 쓸지"를 판단합니다. 그래서 설명을 잘 쓰는 게 매우 중요합니다.

### 에이전트 루프

```
 사용자 질문
     │
     ▼
 ┌─────────┐  "get_service_owner('payment-service') 불러줘"   ┌──────────┐
 │   LLM   │ ───────────────────────────────────────────────▶ │ 파이썬    │
 │ (판단)   │ ◀─────────────────────────────────────────────── │ (실행)    │
 └─────────┘   {"team": "payments", "oncall": "@kim"}         └──────────┘
     │   ↑ 필요하면 여러 번 반복
     ▼
 최종 답변 (더 부를 도구가 없을 때)
```

- `step1`: 이 루프를 직접 코드로 한 바퀴 돌립니다.
- `step2`: `create_agent`가 이 루프를 알아서 돌립니다. 원본 프로젝트(`copilot.py`)도 이 방식입니다.
