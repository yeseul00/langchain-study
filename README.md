AI 에이전트를 처음 접하는 사람을 위한 단계별 실습입니다.
마지막에는 장애 대응 도우미(AI Incident Copilot)를 직접 만들어 보고,
원본 프로젝트(https://github.com/rahulwagh/ai-incident-copilot)와 비교합니다.

모든 실습은 **내 컴퓨터에서만** 돌아갑니다. API 키도, 비용도 필요 없습니다.

## 전체 흐름

| 단계 | 폴더 | 배우는 것 | 핵심 질문 |
| --- | --- | --- | --- |
| 0 | `00_setup` | 환경 준비 | 실습할 준비가 됐나? |
| 1 | `01_llm_basics` | LLM 호출, 시스템 프롬프트, 대화 기록 | LLM은 어떻게 부르고, 왜 이전 대화를 기억 못 할까? |
| 2 | `02_tools_agent` | 도구(Tool), 에이전트 | LLM이 어떻게 "행동"을 하게 될까? |
| 3 | `03_embeddings` | 임베딩, 유사도 | 컴퓨터는 "뜻이 비슷하다"를 어떻게 알까? |
| 4 | `04_rag` | 벡터 검색 + 에이전트 = RAG | LLM이 모르는 우리 회사 정보를 어떻게 답하게 할까? |
| 5 | `05_capstone` | 원본 프로젝트 분석 | 실무용 시스템은 무엇이 더 붙어 있을까? |

각 폴더의 `README.md`를 먼저 읽고, 적힌 순서대로 파이썬 파일을 실행하면 됩니다.

## 먼저 알아둘 단어 5개

- **LLM**: 문장을 받아서 그다음 문장을 만들어내는 모델. 여기서는 Llama 3.1을 씁니다.
- **프롬프트**: LLM에게 넣는 글. "역할 설명 + 질문"으로 구성됩니다.
- **도구(Tool)**: LLM이 대신 호출해 달라고 요청할 수 있는 파이썬 함수.
- **에이전트**: LLM이 "생각 → 도구 호출 → 결과 확인 → 다시 생각"을 반복하며 답을 완성하는 구조.
- **RAG**: 질문과 관련된 자료를 먼저 찾아서 프롬프트에 넣어주는 방식. 모델을 다시 학습시키는 게 아닙니다.
