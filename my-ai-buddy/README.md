# 🐹 내 AI 동료 만들기

AI 동료 한 명을 Lv1부터 Lv5까지 키우면서 LangChain 에이전트를 배우는 과정입니다.
브라우저 채팅 화면에서 동료와 대화하고, **화면 안의 미션**을 깨면서 진행해요.

| 레벨 | 파일 | 동료가 얻는 능력 | 배우는 개념 |
| --- | --- | --- | --- |
| Lv1 | `lv1_talk.py` | 말하기, 성격 | LLM 호출 · 시스템 프롬프트 · 대화 기억 |
| Lv2 | `lv2_hands.py` | 시계·계산기·메뉴 추천·주사위·메모 | 도구(Tool) · 에이전트 |
| Lv3 | `lv3_sense.py` | 말뜻 알아듣기, 기분 눈치 | 임베딩 · 유사도 |
| Lv4 | `lv4_memory.py` | 내 메모 기억하기 | RAG · 벡터 저장소 |
| Lv5 | `lv5_office.py` | 전부 합친 첫 출근 | 완성형 에이전트 → ai office로 |

## 시작하기

`langchain-study` 폴더에서 (가상환경 켠 상태):

```bash
pip install -r requirements.txt          # streamlit 추가 설치 (처음 한 번)
streamlit run my-ai-buddy/lv1_talk.py    # 브라우저가 자동으로 열려요
```

- 다른 레벨로 가려면 터미널에서 `Ctrl+C`로 끄고 파일 이름만 바꿔 실행하세요.
- 코드를 고치고 저장하면 브라우저 오른쪽 위에 **Rerun**이 뜹니다. 누르면 바로 반영돼요.

## 화면 보는 법

- **📖 튜토리얼** (맨 위): 단계별로 따라 하기. **▶ 해보기**를 누르면 보낼 문장 입력이나 스위치 조작을 대신 해 줘요.
  결과를 본 뒤 **🤔 왜 그럴까?**를 펼치면 원리 설명이 나와요. 내용은 `tutorials.py`에서 고칠 수 있어요.
- **🏆 도전 과제**: 튜토리얼을 마친 뒤 혼자 해 보는 미션. 다 깨면 다음 레벨로.
- **💡 원리 요약**: 지금 화면 뒤에서 코드가 무슨 일을 하는지.
- **🔧 도구 사용 기록**: 동료가 어떤 도구를 어떤 값으로 불렀는지.
- **👀 LLM에게 실제로 보낸 내용**: 동료의 답이 **왜 그렇게 나왔는지** 알고 싶으면 이걸 펼치세요.
  LLM이 받은 글이 전부 여기 있어요. 시스템 프롬프트, 지난 대화, 도구 결과까지.

## 나만의 동료로 바꾸기

| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 이름·성격·말투·규칙 | `buddy_config.py` |
| 새 도구 추가 | `buddy_tools.py` (맨 아래 `TOOLS`에 추가) |
| 동료가 기억할 자료 | `my_notes/` 폴더에 `.md` 파일 추가 |

`common.py`는 화면 꾸미기용이라 안 읽어도 됩니다.

## 🧩 나만의 레벨 만들기

튜토리얼을 다 끝냈다면 이제 직접 키워 볼 차례예요.

```bash
cp my-ai-buddy/lv_template.py my-ai-buddy/lv6_my_buddy.py
python -m streamlit run my-ai-buddy/lv6_my_buddy.py
```

- 템플릿에서 ✏️ 표시된 곳(레벨 번호, 제목, 추가 지시, 도구 선택)만 바꾸면 돼요.
- 채팅 화면 규칙은 자동으로 적용돼요: **입력창 하단 고정 · 최신 대화가 맨 위 · 질문과 답은 박스 하나로**.
- 채팅 부분은 `common.chat_area()`가 처리하니 그 아래 패턴은 그대로 두세요.

## 알아두기

- 답이 느리면 정상이에요. 에이전트는 질문 하나에 LLM을 여러 번 부릅니다 (도구 요청 → 결과 확인 → 답).
- `llama3.1:8b`는 작은 모델이라 도구를 안 쓰거나 엉뚱하게 쓸 때가 있어요.
  그럴 때 👀를 펼쳐서 원인을 추리하는 것도 훌륭한 공부입니다.
- `my_notes/`의 맛집·서버 정보는 실습용 가상 정보예요.
